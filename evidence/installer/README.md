  startup. This historical state did not establish Explorer attachment.
- [1.0.4 current-desktop capture](1.0.4/taskbar-current-desktop.png) and

Capture dates are not inferred from filenames or file timestamps. Source and executable hashes
bind each receipt to the actual build. No host restart or sign-out was performed.
