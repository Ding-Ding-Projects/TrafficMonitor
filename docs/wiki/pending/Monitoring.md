# Use the taskbar and tray

After a fresh installed launch, look for the compact traffic meter in the taskbar. The floating main
window starts hidden. The tray menu remains the recovery route for showing that window, opening
settings, changing startup and exiting. If the taskbar surface cannot attach on a particular shell
build, use the tray and report the exact environment rather than assuming the monitor is absent.

## Choose a display

Open the monitor's settings from its tray menu. Taskbar visibility and main-window hiding are
independent saved choices. Showing the floating meter does not require disabling the taskbar meter.
An update must not reset those explicit choices.

## Network selection and traffic history

The retained native interface provides adapter selection and traffic history. Use its existing
network-selection command to choose a connection and its history command to inspect accumulated
traffic. Planned dashboard per-adapter charts are not yet shipped behavior. The observational
snapshot module under development must not change existing accounting totals.

## Exit and recovery

Use the monitor's Exit command for normal closure so it can save settings and traffic history.
Do not terminate unrelated processes. Taskbar attachment has been observed on the selected host;
subsequent sign-in and automatic recovery after an Explorer restart still require separate proof.

The planned native visual redesign includes right-click menus with action search, keyboard access
and a complete adjacent regex workbench. The present wiki records that obligation, not completion.
