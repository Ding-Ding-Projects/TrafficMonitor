Welcome to the TrafficMonitor wiki!

## Maintained native x64 edition

This fork retains TrafficMonitor's native C++/MFC monitoring, taskbar integration and plugin support.
Its unsigned current-user Squirrel.Windows installer includes matching CRT/MFC runtime files.
Fresh installation enables sign-in startup, shows the taskbar monitor and hides the floating main
window. Existing saved choices take precedence.
