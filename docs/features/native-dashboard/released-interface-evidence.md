## Validation and limits

The original and retained image bytes match exactly. All six PNGs were decoded, checked for native geometry/source/hash agreement, inspected for useful content and privacy, and checked for unexpected text metadata. Five deliberate negative checks rejected missing privacy review, a wrong image hash, a wrong source revision, wrong geometry and an incomplete native-render result.

The native evidence uses real process/window facts. Browser console/page diagnostics are inapplicable and no zero browser counters were invented. Private process identities, local paths and original-state records remain outside public source. The images are bounded visual and interaction observations, not complete accessibility, installer, security or long-term reliability proof.

The workspace image was excluded because it retained host/network identity and had incomplete chart rendering. Unsupported/superseded expression examples and the original floating image were also excluded. No redacted derivative replaces an excluded original.

The complete Material Design 3 refinement, bilingual/dark and minimum-size matrix, higher scales, keyboard/UIA/IME behavior and full RegexBuddy parity remain unfinished. Current design references are proposals; later corrected builds require new evidence.
