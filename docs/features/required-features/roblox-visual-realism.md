# Roblox visual realism

Requirement ID: `roblox-visual-realism`. Status: **NOT_APPLICABLE**. Phase: **P5**.

## Required outcome

Roblox games use convincing, recognisable buildings, furniture, animals, NPCs, and machinery, and neither a blocky stand-in nor a block carrying a `SurfaceGui` counts as the real object. Working machines show believable form, materials, support, visible operation, and a timer on an in-world instrument. Quality is accepted only after inspecting native screenshots, ground contact, structural connections, and working interactions.

## Current evidence and limits

TrafficMonitor is a native monitoring application, not a Roblox game.

Listing is not implementation or acceptance proof. PARTIAL still means unfinished.
