# Job Experience Document default product wording

Requirement ID: `job-experience-document-label`. Status: **NOT_APPLICABLE**. Phase: **P5**.

## Required outcome

Every job-related application initially uses the exact English product label `Job Experience Document` instead of `Resume`, with a persisted visible toggle restoring the original wording. Owned labels, actions, guidance and accessible names follow the setting with localization, while filenames, user content, documents and technical interfaces remain unchanged. The exact English term is also an explicitly public-safe private vocabulary noun; the shipped preference remains independent of personal imports.
