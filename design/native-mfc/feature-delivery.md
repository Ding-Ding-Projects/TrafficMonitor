## Explicit boundaries

Repository-specific workspace identity applies when the product actually opens repositories; TrafficMonitor's monitoring workspace is keyed by monitoring profile, and no artificial repository is invented. Browser-extension download handoff is not present in this native monitoring product; adding such an integration would introduce its three real transfer surfaces and evidence. Job-related naming is not applicable to network metrics or settings. A generic source editor is not introduced merely to create an external-editor task, but exported records still offer the required editor handoff. Third-party plugin UI and operating-system consent surfaces retain their owner and are separately disclosed, not falsely labelled as converted.

The taskbar host cannot hold the full dashboard control set at its small physical height. Its native flyout and tray provide the accessible equivalent; all other owned windows retain the full surface obligations. Unsupported platform capabilities remain visible with precise reasons and unfinished evidence rows. None of these boundaries makes a missing applicable tool or feature complete.
